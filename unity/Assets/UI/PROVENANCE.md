# Cat Metro UI visual assets — provenance

Covers the assets under `unity/Assets/UI/**` that are not the audio stingers (their
provenance is recorded separately at `unity/Assets/UI/Audio/PROVENANCE.md`): the six
UI texture PNGs and the `CatMetroSans SDF.asset` TMP font asset. Written at the F-4
round-1-review fix (2026-08-13); the source commit for all assets covered here is
`e86264a` ("milestone: theme screens and audio stingers"), 2026-08-09.

## The six UI texture PNGs

`unity/Assets/UI/Resources/CatMetroUI/Textures/`: `RoundedRect.png`, `SymbolCircle.png`,
`SymbolSquare.png`, `SymbolTriangle.png`, `SymbolDiamond.png`, `SymbolStar.png`.

Verified facts (re-derived directly from the committed files, not from memory):

- All six are 64x64, 8-bit gray+alpha PNGs (confirmed with `file`), i.e. grayscale alpha
  masks with no baked-in color — consistent with how `CatMetroUiTheme`/`WavePreviewStrip`
  apply the palette by tinting `Image.color` at runtime rather than baking color into the
  texture.
- File sizes are small (402-881 bytes each), consistent with simple flat vector-style
  shapes (a rounded rectangle and five geometric symbol silhouettes), not photographic or
  scanned source material.
- They are original work, not third-party stock art or a licensed asset pack: nothing in
  this repository imports or references an external icon/texture package for these paths,
  and no license file accompanies them (unlike the font, below, which does carry one).

**Generation method: UNKNOWN-authored-by-Lane-1B.** The commit that introduced these
files (`e86264a`) does not record the exact tool, script, or step-by-step recipe used to
rasterize them, and no generation script is committed alongside them. Rather than invent
a plausible-sounding recipe after the fact, this entry records that the generation method
is not reconstructible from the repository as committed. They are treated as originally
authored, in-session, non-third-party assets safe to ship, but not as reproducible from a
recorded command the way the audio stingers are.

## `CatMetroSans SDF.asset`

`unity/Assets/UI/Resources/CatMetroUI/Fonts/CatMetroSans SDF.asset` — a TextMeshPro SDF
font asset, generated by TMP's font asset creator from a TrueType source face rather than
authored by hand. Verified facts, read directly from the committed asset's serialized
YAML:

- `m_FaceInfo.m_FamilyName`: `Liberation Sans`, `m_StyleName`: `Regular` — the embedded
  face metrics match the Liberation Sans Regular face byte-for-byte (see the TTF
  byte-identity check below), not a renamed or substituted font.
- `m_SourceFontFileGUID` / `m_SourceFontFile_EditorRef` resolve to
  `unity/Assets/UI/Fonts/LiberationSans.ttf.meta` (GUID
  `4426f4d546f2a4f4cb6957af5af571be`) — the SDF atlas was generated from the copy of the
  font committed under this contract's own `unity/Assets/UI/Fonts/**`, licensed beside it
  at `unity/Assets/UI/Fonts/LiberationSans - OFL.txt` (SIL Open Font License).
- Atlas parameters recorded on the asset: `m_AtlasWidth`/`m_AtlasHeight` 1024x1024,
  `m_AtlasPadding` 9, sampling `pointSize` 86, `m_AtlasRenderMode` raw value `4169` (TMP's
  packed `GlyphRenderMode` enum — an SDF variant; the exact bit-flags are not decoded here
  beyond the raw serialized value, to avoid asserting parameters this note cannot verify).
- What is **not** knowable from the committed asset alone: the exact TMP Font Asset
  Creator invocation (character set string, whether it was the Editor menu flow or a
  scripted `TMP_FontAsset` bake, any custom padding/atlas-resolution choices beyond what's
  serialized above). Those parameters are recorded where they exist in the asset; nothing
  beyond them is claimed.

### LiberationSans.ttf byte-identity check (A-UI-1 verification)

The contract's `A-UI-1` assumption claims the typeface source is "the repo's
already-shipped OFL Liberation Sans, copied with its license." This was previously
unverified. Checked now with `cmp` (byte-for-byte) between the two committed copies:

```
$ cmp unity/Assets/UI/Fonts/LiberationSans.ttf "unity/Assets/TextMesh Pro/Fonts/LiberationSans.ttf"
$ echo $?
0
```

**Result: byte-identical.** Both files are 350,200 bytes with the same SHA-256
(`e5b0af421ea2bfbc1ac8d251d647268087ae82786234c57f757d1f0b90fa8b49`). The
`unity/Assets/UI/Fonts/LiberationSans.ttf` copy this lane committed is not a different or
re-encoded font — it is the exact same file already shipped with the project's TMP
Essentials import at `unity/Assets/TextMesh Pro/Fonts/LiberationSans.ttf`, copied into the
lane's own owned path per the contract's OFL redistribution requirement (license file
committed beside it, not relying on the TMP package's copy remaining installed).
