## State and input timing

`T=n` means the post-step snapshot where `State.Tick == n`: simulation tick `n - 1` has completed and tick `n` has not. `S1@x` means a real player toggle was enqueued while `State.Tick == x`. It is visible immediately in the lever's committed presentation route and counts as one pending toggle, then applies at step 1 when `State.Tick == x + 1`. Do not advance a simulation step between an immediate-input selector and its render.

`alpha` is the real-time interpolation fraction for the current 125 ms tick (`0 <= alpha < 1`); it does not change the authoritative state. For an input moment, render after the real tap has registered, without a touch marker. For every take, record the actual alpha and the capture-time command log; never substitute a command injection, hand placement, or synthetic frame.

Route names below are the authored `S1` routes: `red = E2 -> RED`, `blue = E3 -> BLU`. A queue count is FIFO occupancy at the named node. Train progress is `ProgressTicks / travelTicks` in the authoritative snapshot, before the stated interpolation alpha.

## Required capture receipt for each S1–S6 and D0

The capture operator must create a new receipt per output; this plan supplies none. Include:

- shot ID, candidate commit, package/binary identity, AAB SHA-256, device or checked-in capture-rig identity, `Game` scene, authored level ID, and bundled level JSON SHA-256;
- exact `State.Tick`, outcome, deliveries, `SwitchRoutes`, committed/displayed lever route, pending-toggle count, complete ordered command log, train edge/node/progress list, every node queue count, and alpha (or the immediate-input/pulse phase where applicable);
- HUD-on and HUD-off checklist, actual preview contents, source run state log or before/after clip hash, and any companion seam clip hash;
- raw capture path, raw PNG SHA-256, final export path/SHA-256, pixel-dimension probe, opaque-sRGB/frameless verification, and the stated editorial-layer status (D0 has none);
- gate outcomes and reviewer evidence for G-CONTENT, G-BUILD, G-ART, G-STATE, G-CLEAN, G-FORMAT, G-A11Y, G-13PLUS, plus G-REACH, G-QUEUE, or G-SEAM when the shot list requires them.

Until those live receipts exist, every state and output remains blocked; this document does not assert any capture evidence.
