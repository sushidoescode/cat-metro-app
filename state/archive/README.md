# State archive

Rotated history from `state/PROJECT_STATE.md` (which has a hard line cap — it is mandatory
session-start reading, so every stale line taxes every session). Agents propose rotations;
humans prune. Files here are reference material: agents read them only when investigating
history, never at session start.

Convention: `PROJECT_STATE-<yyyy-mm-dd>.md` — the pruned block, verbatim, date-stamped.
